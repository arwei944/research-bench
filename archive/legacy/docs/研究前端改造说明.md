# Atlas 前端改造说明 · 研究智能体专用前端

> 本说明记录本次将 `atlas-web` 从「通用 coding agent 前端」改造为「研究智能体专用前端」的内容、验证结论与使用方式。

## 改造目标

保留 atlas-web 全部既有功能（会话/文件/终端/设置/分支），在其上叠加**研究智能体门面与工作流入口**：

- 首页 = 研究仪表盘（三大研究场景 + 技能 + 知识库 + 最近项目）
- 工作台 = 原 AppShell（带研究化文案 + 快捷研究模板）
- 两者互跳、数据同源

## 新增功能

| 功能 | 说明 | 位置 |
|---|---|---|
| 研究仪表盘 | 三大场景入口卡片（🔬学科 / 📈金融 / 🎓学习），每场景 2 个预设 prompt；研究技能卡片；知识库树；最近研究项目；进入工作台按钮 | `components/ResearchDashboard.tsx` |
| 仪表盘数据接口 | 读取研究工作区技能（`.pi/skills`/`.atlas/skills`）、知识库树（`knowledge-base/`）、最近会话 | `app/api/research/dashboard/route.ts` |
| 首页分流 | 无参数 → 仪表盘；带 `cwd`/`session`/`workspace` → 工作台（兼容旧深层链接） | `components/HomeGate.tsx` + `app/page.tsx` |
| 工作台快捷模板 | 新会话空状态显示「🔬学科研究·文献综述 / 📈金融研究·财报拆解 / 🎓知识学习·费曼讲解」，点击 `insertIfEmpty` 预填输入框 | `components/ChatWindow.tsx` |
| 侧栏仪表盘入口 | 工作台侧边栏底部第一个按钮「🧠 研究仪表盘」返回首页 | `components/AppShell.tsx` |
| 共享模板源 | 仪表盘与空状态共用一套模板文案 | `lib/research-templates.ts` |

## 品牌与文案研究化

- 产品名：**Atlas 研究智能体**（浏览器标题 / PWA manifest / 登录页 / i18n 三语 / SessionSidebar 标题 / ChatWindow 空状态 / 窗口标题）

## 研究工作区定位

仪表盘 API 按以下优先级定位研究工作区：

1. 环境变量 `ATLAS_RESEARCH_WORKSPACE`
2. 配置文件 `~/.atlas/research-workspace`（纯文本，内容为工作区绝对路径）
