## 2. 启动 / 停止

```bash
# 在工作区根目录
node scripts/atlas-embed.mjs start  . --no-open     # 后台启动（自动分配空闲端口）
node scripts/atlas-embed.mjs status .               # 查看状态
node scripts/atlas-embed.mjs open   .               # 打开浏览器
node scripts/atlas-embed.mjs stop   .               # 停止
node scripts/atlas-embed.mjs serve  .               # 前台运行（调试用）
```

常用选项：

| 选项 | 作用 |
|---|---|
| `-p, --port N` | 固定端口 |
| `-b, --build` | 缺构建产物时自动 `npm run build` |
| `--no-open` | 不自动开浏览器 |

> **首次使用或改了前端代码**，需要先构建：
> ```bash
> cd atlas-web && npm run build
> ```

## 4. 研究通道（本次新增的核心基建）

### 4.1 命令行工具

```bash
node tools/research/research-cli.mjs probe        # 14 通道健康检查
node tools/research/research-cli.mjs snapshot .atlas/research-snapshot.json
```

| 命令 | 用途 |
|---|---|
| `arxiv "<query>" [n]` | arXiv 检索（按提交时间倒序） |
| `paper "<title>" [n]` | Crossref 标题检索 |
| `oa "<query>" [n]` | OpenAlex 检索（按被引排序） |
| `cites <doi> [n]` | **引用网络**：谁引用了这篇 |
| `verify <arXiv:ID \| DOI:10.x \| 标题>` | **引用真实性核验**，输出 ✅/⚠️ |
| `bench <benchmark-id>` | Epoch 基准元信息 |
| `bench-score <bench> <model-ver>` | Epoch **精确分数（含 stderr）** |
| `models [n]` | OpenRouter 价格 / 上下文 |
| `github "<query>" [n]` | 找现成项目 |
| `hn "<query>" [n]` | 社区信号 |
| `hf [n]` | Hugging Face 每日论文 |

### 4.2 通道清单与实测

| 通道 | 分组 | 实测 |
|---|---|---|
| arXiv / Crossref / OpenAlex / Semantic Scholar | 学术 | ✅（S2 免费额度易 429） |
| Epoch AI API / Vals AI / Scale SEAL / ARC Prize / METR | 基准 | ✅ |
| GitHub / Hugging Face / OpenRouter | 工程 | ✅ |

**实测结果：14/14 可用，平均延迟约 1 秒。**

## 6. 已知问题

1. **Node 默认不读 `HTTPS_PROXY`**。本机走代理，`huggingface.co` / `scale.com` 直连会超时。
   - CLI 已自动以 `NODE_USE_ENV_PROXY=1` 重启自身
   - Web API 在 `lib/research-channels.ts` 里显式设置该环境变量
2. **Next.js 16 上游 bug**：内置模块动态 require 失败会抛 `unhandledRejection` 并杀进程。
   `atlas-embed` 已注入 `--unhandled-rejections=warn` 缓解。
3. **Semantic Scholar 免费额度常 429**。需要时自备 key 并设 `S2_API_KEY`。
4. **GitHub 无 token 限 10 次/分钟**。批量检索设 `GITHUB_TOKEN`。
