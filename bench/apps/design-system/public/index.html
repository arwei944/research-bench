◉ 设计系统

10 款外壳设计，每款是一组 token（颜色/圆角/字体/间距/头部高度）。 外壳 CSS 全部读 var(--d-*)，所以换设计只写变量，不动任何前端代码。
这一层被整个外壳共享，改坏了所有应用的外观都会异常。

新增一款设计

往 bench/lib/designs.mjs 的 DESIGNS 数组加一个对象即可，不改前端。

{
  id: "my-style",
  name: "我的风格",
  ref: "参考了哪个产品",
  borrow: "借鉴什么",
  avoid: "刻意不借鉴什么",
  layout: "sidebar-left | sidebar-narrow | top-tabs | command | centered | dashboard | split | rail",
  density: "low | mid | high",
  tokens: { theme:"dark", bg:"#...", panel:"#...", ac:"#...", radius:"8px", ... }
}
