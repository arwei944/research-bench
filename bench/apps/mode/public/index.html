◉ 模式模块

这一层的能力：同一份内容，按使用者水平决定解释深度与参数可见性。 它是被 research / learn 共享的，坏了两边都会降级。

🌱 小白模式

术语带解释 · 出错给怎么修 · 高级参数藏起来

⚡ 专家模式

只给术语 · 完整堆栈 · 全部参数与默认值

应用里怎么用

只需两条 CSS + 标记类名。平台会把模式写进 <html data-mode>。

[data-mode="expert"] .novice-only { display: none !important; }
[data-mode="novice"] .expert-only { display: none !important; }

<div class="novice-only">检索会查 5 个网站，结果都是真实抓的</div>
<div class="expert-only">GET arXiv/OpenAlex · 相关性过滤(A≥0.4)</div>

实时预览接口：GET /api/_platform/mode/preview?sample=lambda
状态文件：bench/data/mode.json（含 perApp 覆盖）
