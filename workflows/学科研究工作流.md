# 工作流 · 学科/学术研究

> 适用:文献调研、论文精读、综述撰写、研究方向探索
> 技能:`/skill:academic-research` + `/skill:research-protocol`
> 沉淀:`knowledge-base/academic/`

## 流程

1. **提问与拆解**(research-protocol 阶段一)
   - 示例:「帮我调研图神经网络在推荐系统领域的最新进展,重点是冷启动问题」
   - 确认:时间范围(近3年?)、范围(全领域 or 子方向)、产出(概述/综述/精读)

2. **多源检索**(阶段二,academic-research §1 + research-channels)
   - 先探通道:`node tools/research/research-cli.mjs probe`
   - 宽检索:`arxiv "<query>" 8` / `oa "<query>" 5`(按被引排序找奠基工作)
   - **顺引用网络走**:`cites <奠基论文DOI> 15` —— 看谁在用它、谁反驳它
   - 生物医学加 PubMed;需要全文时用 Unpaywall 找 open access
   - 补充社区信号:`hn "<关键词>"`(只作线索,不作结论)

3. **筛选与精读**(阶段三,academic-research §2)
   - 20~50 篇候选 → 10~20 篇核心
   - 每篇输出《论文精读卡》

4. **综述写作**(academic-research §3)
   - 按方法谱系/时间线组织,引文全部经 Crossref/arXiv 双通道核验:
     `node tools/research/research-cli.mjs verify <arXiv:ID | DOI | 标题>`
   - 输出 `✅已核验 / ⚠️未找到`;**未核验的一律不写进报告**

5. **质量门禁**(research-protocol §4) → 落盘

## 常用提示词示例
```
/ 帮我写一份关于 [主题] 的调研综述,引用要真实可核验
/ 精读这篇论文: [粘贴 PDF 路径或 DOI]
/ 帮我核验以下引用的真实性: [粘贴引用列表]
/ [主题] 的研究脉络和当前前沿是什么?我该从哪几篇开始读?
```

## 产出规范

- 论文精读卡 → `knowledge-base/academic/精读卡/YYYY-MM-DD-短标题.md`
- frontmatter 遵循 research-protocol §3
