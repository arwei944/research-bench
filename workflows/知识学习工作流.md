# 工作流 · 知识学习

> 适用:新领域入门、概念理解、练习巩固、长期学习管理
> 技能:`/skill:learning-coach` + `/skill:research-protocol`(深究时加 `/skill:academic-research`)
> 沉淀:`knowledge-base/learning/`

## 流程

1. **设定目标**(learning-coach §1)
   - 例:「零基础入门线性代数,目标是能看懂机器学习原理」
   - 确认:基础水平、目标、每周可投入时间

2. **生成学习路径** → 阶段化(0~4),每阶段有资源与可验证成果

3. **逐块教学**(费曼式,learning-coach §2)
   - 一块一个概念:直觉→结构→例子→误区→复述检查
   - **每块结束必问反馈**,根据薄弱点调整节奏

4. **测验与复习**(learning-coach §3/§4)
   - 每主题 5~10 题(记忆→理解→应用→综合)
   - 生成间隔复习计划 + Anki CSV

5. **进度沉淀** → 更新 `knowledge-base/learning/progress.md`

## 常用提示词示例
```
/ 帮我设计一个 [领域] 的学习路径,我从零开始
/ 讲一下 [概念],用费曼方式,最后考我几道题
/ 我的薄弱点是 [主题],出 5 道针对性练习题
/ 帮我生成这周要复习的知识点列表和 Anki 卡片
/ 今天继续上次的 [主题] 学习
```

## 产出规范
- 学习路径 → `knowledge-base/learning/路径-主题.md`
- 讲解/测验记录 → `knowledge-base/learning/笔记-主题.md`
- 进度总表 → `knowledge-base/learning/progress.md`(持续更新)
