# 工作流 · 金融研究

> 适用:上市公司研究、行业研究、财报解读、估值分析、投资主题调研
> 技能:`/skill:finance-research` + `/skill:research-protocol`
> 沉淀:`knowledge-base/finance/`

## 流程

1. **明确对象与数据时点**
   - 例:「分析宁德时代 2025 年报」「对比拼多多与阿里巴巴的盈利质量」
   - 确认:数据截至日期、是否需要行情数据、产出类型(简报/深度报告)

2. **数据获取**(finance-research §1)
   - 美股:引导用户提供财报文件,或用 SEC EDGAR
   - A股:巨潮资讯/交易所披露;宏观:官方统计
   - **拿不到的数字明确标注"未获取",绝不编造**

3. **框架分析**(finance-research §2)
   - 公司研究 / 行业研究 / 估值(含假设与敏感性)

   > 补充：技术侧信号可用 `research-channels` 的 `github` / `hn` / `vals` 通道，但**财务数字仍必须来自官方披露**，通道只能作线索。

4. **成稿**(finance-research §3 模板)
   - 事实/观点分离、每个数字溯源、显著标注数据日期

5. **逆向检查 + 免责声明** → 落盘

## 常用提示词示例
```
/ 分析这家公司的基本面: [公司名],请先说明需要哪些数据
/ 解读这份财报: [粘贴/路径],重点看盈利质量和现金流
/ [行业] 竞争格局与关键跟踪指标是什么?
/ 帮我搭建一个 [公司] 的估值框架,标出关键假设
```

## 产出规范
- 研究报告 → `knowledge-base/finance/YYYY-MM-DD-公司或主题.md`
- 跟踪表格 → `knowledge-base/finance/跟踪表-公司名.md`
- 每个报告头部必须有:研究日期、数据截至、置信度、来源清单、免责声明
