## 4. 概率与统计（最容易被误用的部分）

### 4.1 基础

| 词 | 说明 |
|---|---|
| 样本空间 / 事件 · | |
| 条件概率 ★ | `P(A\|B)` |
| 独立 / 条件独立 ☆ | 朴素贝叶斯的前提 |
| 全概率公式 / 贝叶斯公式 ★ | 更新信念、诊断、平滑 |
| 先验 / 似然 / 后验 ★ | prior / likelihood / posterior |
| 期望 expectation ★ | 平均值；注意「期望≠常见值」 |
| 方差 / 标准差 ★ | `ddof=0` 还是 `1`？样本 vs 总体 |
| 协方差 / 相关系数 ★ | 相关≠因果 |
| 偏度 / 峰度 · | 分布形状 |
| 大数定律 LLN ☆ | 采样够多就收敛 |
| 中心极限定理 CLT ★ | 均值近似正态 → 置信区间的基础 |
| 重尾 / 幂律 ☆ | 均值无意义；别用均值汇报延迟 |
| 长尾 / 齐夫分布 ☆ | 词频、请求分布 |

### 4.2 分布（会认 + 会用）

| 分布 | 用在哪 |
|---|---|
| 伯努利 Bernoulli ★ | 一次成功/失败 |
| 二项 Binomial ☆ | n 次里成功 k 次（CTR、通过率） |
| 泊松 Poisson ☆ | 单位时间事件数（请求到达） |
| 几何 Geometric ☆ | 首次成功所需次数（重试） |
| 均匀 Uniform ★ | `random()` |
| 正态 Gaussian ★ | 噪声、CLT 极限 |
| 指数 Exponential ☆ | 间隔时间（队列） |
| Beta ★ | 比例的先验（A/B 的贝叶斯版） |
| Dirichlet ☆ | 多项分布的共轭先验（主题模型） |
| 对数正态 Log-normal ☆ | 延迟、收入——**汇报中位数而非均值** |
| t 分布 ☆ | 小样本均值 |
| 卡方 / F · | 方差分析、拟合优度 |

### 4.3 估计与推断

| 词 | 说明 |
|---|---|
| 最大似然估计 MLE ★ | 最常用拟合方法 |
| 最大后验 MAP ☆ | MLE + 先验（= 加正则） |
| 矩估计 · | 简单但粗糙 |
| 无偏估计 ☆ | `E[θ̂]=θ`；样本方差要 `n-1` |
| 一致估计 · | 样本→∞ 收敛到真值 |
| 有效估计 / 最小方差 · | |
| 共轭先验 conjugate prior ☆ | 算起来方便 |
| 置信区间 CI ★ | 常被误解：不是「参数有 95% 概率落在里面」 |
| 自举 bootstrap ★ | 不靠分布假设估 CI，工程上最好用 |
| 置换检验 permutation test ☆ | 非参数 A/B |
| 假设检验 ★ | H0/H1、显著性水平 α |
| p 值 ★ | 「H0 为真时观察到这么极端结果的概率」——**不是「H0 为真的概率」** |
| 第一类/第二类错误 ☆ | 误报 / 漏报 |
| 统计功效 power ☆ | 1-β，需要多少样本才测得出来 |
| 效应量 effect size ☆ | Cohen's d；比 p 值更有信息 |
| 多重比较校正 ☆ | Bonferroni / Benjamini–Hochberg FDR |
| 序贯检验 / 偷看问题 ☆ | A/B 中途反复看 p 值会假阳性膨胀 |
| 分层 / 阻断 stratification ☆ | 降方差 |
| 倾向得分 · | 观察性因果 |
| 信度 / 效度 · | 测量质量 |

| 精确率 / 召回率 / F1 ★ | precision / recall / F1 |
| 混淆矩阵 ★ | |
| 交叉验证 ★ | k-fold，别在时序数据上随机切 |
| 过拟合 / 欠拟合 ★ | |
| 偏差-方差分解 ★ | 误差 = 偏差² + 方差 + 噪声 |

## 15. 最容易踩的 12 个坑（都是数学没想清）

1. **平均值汇报延迟** → 重尾分布下无意义，用 p50/p95/p99
2. **浮点相等比较** → 用 `abs(a-b) < eps` 或 `math.isclose`
3. **`E[x²] - E[x]²` 算方差** → 灾难性抵消，用 Welford
4. **`exp` 直接算 softmax** → 上溢，先减 max
5. **p 值理解错** → 它**不是**「H0 为真的概率」
6. **A/B 中途反复看结果** → 假阳性膨胀，需序贯检验
7. **时序数据随机切训练/测试** → 信息泄漏
8. **相关当因果** → 混淆变量
9. **自定义比较器不满足全序** → `sort` 行为未定义（甚至崩）
10. **`ddof` 用错** → 样本/总体方差混用
11. **KL 当距离用** → 它不对称，不满足三角不等式
12. **整数除法 / 取模负数** → Python `-7 % 3 == 2`，C 是 `-1`
