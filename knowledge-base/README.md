# 知识库 Knowledge Base

个人研究智能体的长期记忆。所有研究产出的统一落盘位置。

## 目录结构

```
knowledge-base/
├── README.md          # 本索引
├── academic/          # 学科/学术研究产出
│   ├── 综述与调研报告
│   ├── 论文精读卡/
│   └── 学习路线/
├── finance/           # 金融研究产出
│   ├── 公司研究
│   ├── 行业研究
│   └── 跟踪表/
├── learning/          # 知识学习产出
│   ├── 学习路径
│   ├── 讲解与测验笔记
│   └── progress.md    # 学习进度总表
├── projects/          # 跨领域主题项目
└── inbox/             # 快速随手笔记(定期归档到上面)
```

## 命名规范
- 统一格式:`YYYY-MM-DD-主题.md`
- 英文/中文均可,主题简短清晰
- 研究类文件在头部加 YAML frontmatter:
  ```yaml
  ---
  title: 主题
  date: YYYY-MM-DD
  domain: academic|finance|learning
  confidence: high|medium|low
  sources: [来源1, 来源2]
  status: active|reference
  ---
  ```

## 使用规则
1. **凡研究必沉淀**:任何一次调研/分析/学习结束,产出写入对应目录。
2. **跨会话检索**:新任务开始前,先检查知识库是否已有相关主题,站在已有结论上前进。
3. **更新而非覆盖**:补充新发现时,在原文追加「更新日志」小节,保留演进记录。
4. **定期归档**:`inbox/` 的随手笔记每月整理到正式目录。
