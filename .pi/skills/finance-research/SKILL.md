# Finance Research · 金融研究

> 前置:本技能基于 research-protocol,质量守则一致。
> 重要声明:本技能提供研究辅助,不构成投资建议。所有结论必须标注数据日期与不确定性。

## 1. 数据获取(零成本 + 权威优先)

### 1.1 权威免费数据源
| 需求 | 数据源 | 说明 |
|---|---|---|
| 美股财报/公告 | **SEC EDGAR** `https://www.sec.gov/edgar/search/` | 权威一手数据;Filing (10-K/10-Q/8-K) 免费;API 需 User-Agent 头 |
| A股财报/公告 | 上交所/深交所官网披露、巨潮资讯 `cninfo.com.cn` | 权威一手 |
| 宏观数据 | 国家统计局、央行、美联储、Wind/Choice 免费版 | 权威 |
| 实时行情 | 公开行情接口(稳定性有限),或用户提供截图/数据 | 二手,标注时效 |

### 1.2 获取方式(给 agent 的指令)
- **优先引导用户提供或确认**数据来源;不要编造行情数字。
- 需要在线抓取时,记录实际使用的 URL 与抓取日期。
- **禁止虚构任何行情、财报数字。** 拿不到就明说"该数据未能获取",绝不推测填充。

## 2. 分析框架(三类常用)

### 2.1 公司研究(基本面)
```
1. 公司概览:主营业务、收入结构、商业模式一句话
2. 财务拆解(最近 2~3 期):
   - 收入/利润同比增速
   - 毛利率/净利率趋势
   - 现金流 vs 利润质量
   - 资产负债与杠杆
3. 竞争格局:市场份额、护城河(品牌/网络/成本/转换成本)
4. 增长驱动与风险:催化剂 + 关键风险(各列 3~5 条)
5. 估值(见 2.3)
```

### 2.2 行业研究
```
1. 行业规模与增速(标注数据来源与年份)
2. 产业链位置与上下游议价力
3. 竞争格局(CR3/CR5、龙头)
4. 驱动因素(PEST 或波特五力)
5. 关键跟踪指标
```

### 2.3 估值工具(概念性,非精确建议)
- 相对估值:PE / PB / PS,与自身历史分位、同行对比。
- 绝对估值:DCF 简述(假设前提必须列出,敏感性分析)。
- **估值结论一律标注**:数据截至日期、假设、不确定性。

## 4. 纪律性守则(强制)
1. **事实与观点分离**:数据是事实(标来源),判断是观点(标依据)。
2. **数字必须溯源**:每个关键数字带来源与日期;无法溯源的数字不出现。
3. **时效披露**:行情/财报都有时点,报告中显著标注"数据截至 YYYY-MM-DD"。
4. **逆向检查**:给出看多结论时,主动列出最强看空理由;反之亦然。
5. **不确定优先**:没把握就说没把握,宁缺毋滥。
