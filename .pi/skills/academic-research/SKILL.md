# Academic Research · 学科/学术研究

> 前置:本技能基于 research-protocol。涉及通用质量守则时遵循之。
> 原则:零成本、开放数据源、引用可核验。

## 1. 学术检索(免费开放 API)

### 1.1 arXiv(预印本,计算机/物理/数学/量化金融等)
通过 HTTP API 检索(注意用 HTTPS):
```
# 例:搜索全字段 "graph neural network" 最新 20 篇
curl -s "https://export.arxiv.org/api/query?search_query=all:%22graph+neural+network%22&start=0&max_results=20&sortBy=submittedDate&sortOrder=descending"
```
- 解析 `<entry>`:`<title>`、`<published>`、`<id>`(arxiv id)、`<summary>`(摘要)、`<author>`。
- 换 title 检索用 `ti:` 前缀;精确短语用双引号 + `%22`。

### 1.2 PubMed / PMC(生物医学)
E-utilities:
```
# esearch 拿 PMID
curl -s "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esearch.fcgi?db=pubmed&term=causal+inference+diabetes&retmax=20&retmode=json"
# 用 PMID 拉摘要(efetch)
curl -s "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=pubmed&id=PMID1,PMID2&retmode=text"
```
- 免费、无需 key(限频;批量请注册 NCBI API key)。

### 1.3 Crossref(论文元数据 / 引用核验)
```
# 按标题查论文(返回 DOI)
curl -s "https://api.crossref.org/works?query.bibliographic=papers+title&rows=3"
# 按特定 DOI 验证
curl -s "https://api.crossref.org/works/10.xxxx/xxxxx"
```
- 核验引用:**真实存在** = Crossref 返回该 DOI 且标题/作者相符。不匹配一律标 ⚠️未找到。

### 1.4 其他
- Semantic Scholar API:`https://api.semanticscholar.org/graph/v1/paper/search?query=...`(需限频)
- 开放获取全文:Unpaywall `https://api.unpaywall.org/v2/{DOI}?email=you@example.com`

## 2. 论文精读流程
对单篇论文(用户提供 PDF 或检索到的 open access PDF):
1. 读摘要 + 引言末尾 → 提炼:**要解决的问题、方法、主要发现**。
2. 读方法/实验 → 提炼:**数据集、基线、关键指标**。
3. 读结论与局限 → 提炼:**作者自述的不足**。
4. 输出《论文精读卡》:
   ```markdown
   ## 论文精读卡
   - 标题 / 作者 / 年份 / Venue / DOI
   - 问题:...
   - 方法:...
   - 关键结果:...(指标数字, 含对比基线)
   - 局限:...
   - 对我们的价值:...
   ```
5. 精读卡保存到 `knowledge-base/academic/`。

## 3. 文献综述流程
1. 检索 20~50 篇候选 → 筛出 10~20 篇核心。
2. 每篇做精读卡(可精简)。
3. 按主题/时间线组织成综述结构:
   - 引言(研究背景与问题)
   - 方法谱系(按方法类型分组论述)
   - 各方向的进展与不足
   - 开放问题与未来方向
   - **引用核验清单**(全部经 Crossref 校验)
4. 遵循 research-protocol 的报告模板与质量门禁。

## 4. 引用核验(强制)
- 用户在写作中给出的一切引用,逐一用 Crossref 校验。
- 输出格式:
  ```
  1. Walters WH, Wilder EI. Fabrication and errors in the bibliographic citations generated by ChatGPT. Scientific Reports, 2023, 13:14045. DOI: 10.1038/s41598-023-41032-5 ✅已核验
  ```
- 发现虚构引用时明确提示:`⚠️ 该引用疑似虚构(Crossref 未检索到),请移除或替换`。

## 5. 学科知识的呈现
- 面对"帮我了解 XXX 方向"类请求,输出结构:核心概念 → 关键论文/里程碑 → 当前前沿 → 开放问题 → 入门资源。
- 结合费曼原则:先用直觉语言讲清概念,再给严谨定义。
